# API

FastAPI-сервис каталога. Принимает данные товара от бота, управляет транзакцией PostgreSQL и сохраняет изображения в MinIO через S3 API.

## Структура

- `app/routers/` - HTTP-эндпоинты.
- `app/api/` - зависимости, разбор загрузок и обработчики HTTP-ошибок.
- `app/schemas/` - Pydantic-модели запросов и ответов.
- `app/services/` - создание и чтение товаров, границы транзакций.
- `app/repositories/` - запросы к БД и операции с изображениями.
- `app/db/` - SQLAlchemy-модели, engine и сессии.
- `app/core/` - конфигурация, логирование и создание S3-клиента.
- `alembic/` - миграции, выполняемые отдельным сервисом Compose.

## Эндпоинты

| Метод | Путь | Назначение |
| --- | --- | --- |
| GET | `/api/v1/products` | Публичный список товаров |
| GET | `/api/v1/products/{id}/image` | Изображение с его Content-Type |
| POST | `/api/v1/products` | Multipart: title, source_chat_id, source_message_id, photo; требуется X-Service-Token |
| GET | `/health` | Базовая HTTP-проверка, без опроса хранилищ |

Повторная обработка исходного сообщения возвращает прежний товар. Конкуренцию контролируют UNIQUE в PostgreSQL и INSERT ON CONFLICT DO NOTHING. Только запрос, вставивший запись, загружает изображение; commit выполняется после загрузки. S3-ключ содержит chat ID, message ID и SHA-256 содержимого.

SQLAlchemy-сессия создаётся на запрос. S3-клиент создаётся на процесс в lifespan, синхронные операции выполняются через `asyncio.to_thread`. Бакет создаётся при старте, если отсутствует. Связь PostgreSQL и S3 не является общей транзакцией.

Параметры сервиса, миграции, запуск и проверки описаны в [главном README](../../README.md).
